About GameFinder

GameFinder is a frontend-only Computer Engineering project for discovering games and software based on PC requirements. It demonstrates HTML5, CSS3, JavaScript arrays/objects, filtering, sorting, localStorage and responsive UI design.

⚠️ Requirement values in this project are demo/sample values. Always check the official product requirements before installing or purchasing software or games.
